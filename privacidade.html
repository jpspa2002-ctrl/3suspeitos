Política de Privacidade

Vigente desde 19 de novembro de 2026

Esta política vale para o site da série 3 Suspeitos e para o aplicativo 3 Suspeitos Publisher, uma ferramenta interna usada apenas pelo criador da série para publicar os vídeos dela nos canais dele no YouTube e no TikTok.

1. Quem usa o aplicativo

Só o criador da série. O aplicativo não é oferecido ao público, não tem cadastro e não coleta dados de espectadores ou de outras pessoas.

2. Quais dados o aplicativo acessa

  • Google / YouTube: com a autorização do criador, o aplicativo usa os escopos youtube.upload e youtube para enviar vídeos ao canal do criador, definir título, descrição e horário de publicação, e deixar privado ou remover um vídeo da própria série.
  • TikTok: com a autorização do criador, o aplicativo usa user.info.basic (identificador, nome de exibição e foto do perfil do criador), video.upload e video.publish para publicar os vídeos da série na conta do criador.

3. Como os dados são guardados

Os tokens de acesso ficam salvos apenas no computador do criador. O aplicativo não tem servidor próprio e não envia esses dados a ninguém além das próprias plataformas (Google e TikTok), no momento de publicar.

4. Compartilhamento

Nenhum dado é vendido, alugado ou compartilhado com terceiros, nem usado para publicidade.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Como revogar o acesso e apagar os dados

  • Google: em myaccount.google.com/permissions, remova o acesso do "3 Suspeitos".
  • TikTok: no app, em Configurações e privacidade → Segurança → Apps e serviços, remova o "3 Suspeitos".
  • Ao revogar, os tokens guardados no computador do criador deixam de funcionar e são apagados.

6. Visitantes deste site

Este site não usa cookies, formulários nem ferramentas de análise. Ele é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso (como endereço IP) conforme a política de privacidade do GitHub.

7. Crianças

A série não é destinada a crianças, e o aplicativo não coleta dados de crianças.

8. Mudanças e contato

Se esta política mudar, a nova versão aparece nesta página com a data atualizada. Dúvidas: jpspa2002@gmail.com.

Privacy Policy

Effective November 19, 2026

This policy covers the 3 Suspeitos website and 3 Suspeitos Publisher, a private, internal desktop tool used only by the series' creator to publish the series' own videos to the creator's own YouTube channel and TikTok account.

Users

The tool is used only by the creator. It is not offered to the public, has no sign-up, and collects no data from viewers or anyone else.

Data accessed

  • Google / YouTube (youtube.upload, youtube): upload videos to the creator's channel, set title, description and publish time, and make private or delete the series' own videos.
  • TikTok (user.info.basic, video.upload, video.publish): read the creator's basic profile (ID, display name, avatar) and publish the series' videos to the creator's account.

Storage and sharing

Access tokens are stored only on the creator's computer. There is no server. No data is sold, rented, shared with third parties or used for advertising. 3 Suspeitos Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions and in TikTok under Settings and privacy → Security → Apps and services. Revoking access invalidates and deletes the stored tokens.

Website visitors and children

This website uses no cookies, forms or analytics; it is hosted on GitHub Pages, which may log technical access data under GitHub's privacy statement. The series is not directed to children and the tool collects no data from children.
